# IoT-Driven Movers Transport System

## Project Overview
This project is an IoT-based system designed to monitor and track the transportation of agricultural produce in real time. The system captures temperature, humidity, and vehicle location data and displays it on a web-based dashboard to improve efficiency, transparency, and reduce post-harvest losses.

## Features
- Real-time vehicle tracking
- Environmental monitoring (temperature & humidity)
- Cloud-based data storage
- Web dashboard for farmers and transporters
- User authentication and role management

## Technologies Used
- Backend: Node.js / Express
- Frontend: HTML, CSS, JavaScript
- Database: MySQL
- IoT Device: ESP8266 (simulated)
- Hosting: Render
- Version Control: Git & GitHub
